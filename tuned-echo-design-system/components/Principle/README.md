# Principle

A short claim with a serif lead-in and a vertical pill marker in a key color.

**Markup:** `<li class="te-principle"><i style="background:var(--key-…)"></i><span><strong>Lead-in.</strong>Explanation.</span></li>` inside a list grid of `repeat(auto-fit, minmax(15rem, 1fr))`.

- Lead-ins are a short sentence ending in a period, set in `callout` (serif roman, not bold).
- Assign markers in strip order (pink, orange, yellow, green, blue, purple) down the list. Six items max, so each color appears once.
- Use for house style, values, deliverables or "what you get" lists. Not for steps in a sequence (use MethodStep).
