# Eyebrow

A small condensed uppercase label that names a section above its heading.

**Markup:** `<p class="te-eyebrow">How we work</p>`, written in sentence case; CSS uppercases it.

- `eyebrow` style: `cond` family, 12.8px, letter-spacing 0.18em, `muted`.
- Two to five words. It names the section ("Working examples", "House style"); the heading below makes the claim.
- The only place Oswald appears, besides the seal lettering and the development banner.
