# MethodStep

One movement of the method, with a colored dot, a serif title and a short description under a top rule.

**Markup:** `<div class="te-step"><h3><i class="dot" style="background:var(--key-…)"></i>Title</h3><p>Description</p></div>`, placed in a grid of `repeat(auto-fit, minmax(13rem, 1fr))` with a 32px/40px gap.

- The method is always four steps in this order and color: Listen (`key-pink`), Trace (`key-yellow`), Tune (`key-green`), Echo (`key-blue`).
- The title is one word. The description opens with a short imperative sentence ("Write the plan as the record.").
- Also usable for numbered phases in proposals and SOWs; keep the dot colors in strip order.
